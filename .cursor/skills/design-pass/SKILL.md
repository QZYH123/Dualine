# Design pass

Before calling a screen done:

1. **Glance test:** Would you be embarrassed to open this full-screen for 3 seconds?
2. **Type:** Distinct pairing; readable measure for prose; code font that doesn’t fight the prose.
3. **Space:** Consistent scale; no cramped toolbars; breathing room between panes.
4. **Color:** Limited palette + one accent; dark or light both OK if intentional.
5. **Motion:** Only if it clarifies prose↔code mapping.
6. **Remove:** One decorative element; one competing control.

Reject: purple gradients, glassmorphism piles, emoji headers, “hero SaaS” marketing chrome inside the reader.
